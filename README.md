# Bagheera

A delivery harness on Claude Code for an engineering org of ~100 engineers: knowledge management across the org, standards applied everywhere, one confusion-free path for developers, PMs inside the development loop, and visibility for leadership.

**Where things stand (2026-11-04):** all six design docs are approved, and [the plan](docs/plan.md) is drafted for the owner's review. The first system to build is the delivery path and a simple knowledge library, piloted by one team on at least 10 tickets; the rest of the design is added one part at a time.

- [Product requirements](docs/prd.md) — the source of truth; changes made to match the owner's decisions are logged in the [design index](docs/design/README.md#prd-changes)
- [Plan](docs/plan.md) — what's built first, the pilot, what's added and when, rollout, and tests
- [Architecture](docs/architecture.md) — the first sketch, from 2026-10-26; the design docs and decisions replace it where they differ
- [Decisions](docs/decisions/) — the owner's decisions, one short record each
- [Design docs](docs/design/README.md) — the full design, area by area
- [Pitch deck](docs/pitch-deck.pptx) ([PDF](docs/pitch-deck.pdf)) — 11 slides for product and engineering leadership, made before the design docs
