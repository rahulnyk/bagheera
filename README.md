# Bagheera

A delivery harness on Claude Code for an engineering org of ~100 engineers: knowledge management across the org, standards applied everywhere, one confusion-free path for developers, PMs inside the development loop, and visibility for leadership.

**Where things stand (2026-11-04):** all six design docs are approved. The first system to build is the delivery path and a simple knowledge library ([decision 0069](docs/decisions/0069-first-system-delivery-path-and-knowledge-library.md), with the library rules in [0070](docs/decisions/0070-knowledge-expires-and-every-change-is-checked-once.md) and [0071](docs/decisions/0071-newest-wins-and-approvers-recorded-on-each-page.md)). The phased plan, `docs/plan.md`, is next.
