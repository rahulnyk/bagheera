# Name the knowledge library Council Rock and the knowledge agent Baloo

## Context and problem statement

Jungle Book names are allowed for a few top-level components, each proposed to the owner first ([0006](0006-plain-names-a-few-themed-ones.md)). The knowledge library and the knowledge agent are the two main components of design doc 1.

## Considered options

* A. Council Rock for the library; Baloo for the agent
* B. Hathi for the library; Baloo for the agent
* C. Plain names only

## Decision outcome

Chosen option: A. Council Rock is where the wolf pack meets and the Law of the Jungle is upheld: a shared home for standards and decisions. Baloo teaches Mowgli the Law: the agent that gathers and passes on what the team learns. Commands, files and workflows keep plain names, and docs show the plain name alongside, for example "Council Rock (the knowledge library)".
