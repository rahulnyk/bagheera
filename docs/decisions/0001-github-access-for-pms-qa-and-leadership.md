# PMs work in GitHub, with their own accounts

## Context and problem statement

PMs and tech leads review and approve stage documents in the ticket's pull request, and answer questions there (PRD C1, C2). Tech leads already have GitHub accounts; PMs often don't. This is PRD open question Q2.

## Considered options

* GitHub accounts for PMs
* Keep approvals and questions outside GitHub, in Jira or a separate page

## Decision outcome

Chosen option: GitHub accounts for PMs, with access to the team's repos. The owner confirmed this can be arranged easily.

### Consequences

* Good, because PMs comment and approve where the work happens, with no extra tool.
* Bad, because every PM needs a GitHub seat.
