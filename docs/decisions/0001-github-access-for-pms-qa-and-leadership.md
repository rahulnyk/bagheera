# Give PMs, QA and leadership GitHub accounts

## Context and problem statement

PMs and QA review and approve stage documents in pull requests (PRD C1, C2), and the dashboard sits next to the work (V1–V3). Both need GitHub accounts. This is PRD open question Q2.

## Considered options

* GitHub accounts for PMs, QA and leadership
* Keep approvals and status outside GitHub (Jira or a separate page)

## Decision outcome

Chosen option: GitHub accounts for PMs, QA and leadership. The owner confirmed this can be arranged easily.

### Consequences

* Good, because PMs and QA comment and approve where the work happens, with no extra tool.
* Good, because leadership can open the dashboard and the linked PRs directly.
* Bad, because every PM, QA engineer and leader needs a GitHub seat.
