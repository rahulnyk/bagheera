# Keep one master knowledge library

## Context and problem statement

PRD Q5 asks whether there is one org-wide knowledge base or one per domain with shared standards.

## Considered options

* One master knowledge library for the whole org
* One per domain, with a shared standards library

## Decision outcome

Chosen option: one master knowledge library. If it grows too big, add a hierarchy later. Design doc 1 suggests a folder layout that makes a later split easy.

### Consequences

* Good, because there is one place to look, one set of checks and one curation flow.
* Bad, because the library may need restructuring as it grows.
