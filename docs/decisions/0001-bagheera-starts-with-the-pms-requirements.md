# Bagheera's first job is helping PMs write the requirements

## Context and problem statement

In practice, development is seldom what holds a feature up; the product requirements are. Where should Bagheera put most of its help?

## Decision outcome

Set by the owner: at the start, with the PM.

* The first stage, Spec, is drafted with the PM from the ticket, its linked pages, the wiki and the code.
* The wiki exists to help PMs write requirements as much as to help developers build.

### Consequences

* Good, because help goes where features wait longest.
* Good, because each merged feature makes the next spec easier to write.
* Bad, because PMs need somewhere to work that isn't developer tooling ([0002](0002-pms-work-in-a-portal.md)).
