# Call the dashboard "Bagheera dashboard"

## Context and problem statement

Themed names are only for a few top-level components, where a name helps, each proposed to the owner first ([0010](0010-naming.md)). The dashboard is an org-level GitHub Project ([0051](0051-dashboard-on-an-org-github-project.md)); its title is what people search for in the org's projects, and what the docs, the weekly summary and the Jira comment call it. What is it called?

## Considered options

* A. A plain name: "Bagheera dashboard"
* B. A themed name: "Chil", after the kite who watches the whole jungle from above and carries news, shown as "Chil (the Bagheera dashboard)"

## Decision outcome

Chosen option: A. The GitHub Project is titled "Bagheera dashboard", and the weekly summary is "Bagheera weekly summary". The themed names stay at three: Bagheera, Council Rock and Baloo.

### Consequences

* Good, because there's nothing to learn, and it's easy to find in the org's list of projects.
* Neutral: people will say "the dashboard" either way.
